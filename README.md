# Библиотечная система (Layered Architecture)
Полная реализация лабораторной работы на PHP.

## Запуск
1. Импортируйте `docs/db_schema.sql` в MySQL (создайте БД `library_db`).
2. В `src/Presentation/index.php` укажите свои логин/пароль от БД.
3. Запустите: `php -S localhost:8000 -t src/Presentation`
